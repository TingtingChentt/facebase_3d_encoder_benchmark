## LaTeX macro blocks

The manuscript quotes no number inline; every value is a `\newcommand` emitted
by a script. `results/paper_macros/` holds the blocks exactly as the manuscript
`\input`s them, and each is regenerated by:

| Macro file | Emitter | Covers |
|---|---|---|
| `numbers_trainseed.tex` | `emit_numbers_trainseed.py` | the 5-training-seed sweep (`\ts*`) — **the headline numbers** |
| `numbers_leak_trainseed.tex` | `emit_numbers_leak_trainseed.py` | subject-leakage contrast, both arms at 5 seeds |
| `numbers_xsitefix.tex`, `numbers_xsitefix_bin.tex` | `emit_numbers_xsite.py --fix [--binary]` | leave-one-site-out, 4-class and binary |
| `numbers_perclass_trainseed.tex` | `emit_perclass.py --family trainseed` | per-class softmax vs. prototype decomposition |
| `numbers_recog.tex` | `recognizability.py` | class size vs. per-class F1 |
| `numbers_errconc.tex` | `error_concentration.py` | error concentration and RASopathy confusions |
| `numbers.tex`, `numbers_leak.tex` | `emit_numbers.py`, `emit_numbers_scanlevel.py` | cohort counts and the single-checkpoint analyses the sweep does not cover |

Regenerating a macro block rewrites only the provenance comment lines (which
name the generator's path); every `\newcommand` value is reproduced exactly.

## Naming inside the code

Task keys in `facebench/eval/rerun_config.py` map to the paper as:

| Key | Paper task |
|---|---|
| `A1_fix` | four-class cleft subtyping (early stopping disabled — the reported arm) |
| `A2_fix` | binary cleft screening (early stopping disabled — the reported arm) |
| `B1_corrected` | 19-class syndrome category |
| `B2_corrected` | 33-class clinical diagnosis |
| `C_corrected` | combined affected-vs-unaffected screening |
| `B{1,2}_scanlevel` | the leaked scan-level arm of the leakage contrast |
| `XS_fix_*`, `XSB_fix_*` | leave-one-site-out folds, four-class and binary |

`A1`/`A2` (without `_fix`) are the earlier patience-20 runs. They are kept
because the paper's stopping-rule analysis contrasts the two, and because
`legacy_z` in the summary files reports where each single pre-sweep checkpoint
falls in the retrained distribution. They are **not** the reported arm.
